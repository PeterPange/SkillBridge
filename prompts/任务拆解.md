# SkillBridge × Emdash 任务拆解

> 在 Emdash(Web 版)里按阶段建任务,每个任务的提示词直接复制本文档对应小节。
> 规则:先合地基再开上层;同阶段任务并行,互不碰同一文件。

## 阶段 0:项目骨架(必须最先合并)

```
阅读 prompts/大纲.md 了解项目全貌。

搭建 SkillBridge 项目骨架:
1. Python 3.11 + pyproject.toml(uv 管理),包结构按 README.md 目录规划
2. docker-compose.yml:Neo4j + PostgreSQL(pgvector/pgvector 镜像),带健康检查
3. .env.example 列出全部环境变量
4. Makefile:make up / make down / make test
5. 冒烟测试:连接 Neo4j 和 Postgres 各跑一个查询

验收:docker compose up -d 后 pytest 通过,不调任何外部 API。
不要实现业务模块,只搭骨架。
```

## 阶段 1A:数据采集(可与 1B 并行)

```
阅读 prompts/大纲.md 第二、三节。

实现数据采集模块 data/:
1. ESCO/O*NET 岗位与技能数据拉取(官方 API/数据集,离线缓存到 data/raw/)
2. Microsoft Learn 课程元数据采集(课程名/难度/时长/学习目标/URL)
3. 模拟员工数据生成器(10 名员工,技能等级 0-4,含 Evidence 字段)
4. 统一 JSON Schema 落盘到 data/processed/

验收:python -m data.collect 一次跑通,产出三类 JSON 文件 + pytest 覆盖 schema 校验。
网络不可用时使用本地 fixture,不阻塞测试。
```

## 阶段 1B:技能归一化(可与 1A 并行)

```
阅读 prompts/大纲.md 第三节(Skill Normalization)。

实现 skill_normalization/:
1. 文本标准化(大小写/别名表/同义词)
2. Embedding 相似度匹配(sentence-transformers,本地模型)
3. LLM 语义校验兜底(可选开关,无 API key 时跳过)
4. 输出统一 skill_id 映射表

验收:GenAI/Generative AI/生成式AI 等输入全部归一到同一 skill_id;pytest 覆盖。
```

## 阶段 2A:知识图谱(依赖阶段 0/1)

```
阅读 prompts/大纲.md 第四节。

实现 knowledge_graph/:
1. Neo4j 图模型:Employee/Position/Skill/Course 节点
   关系:HAS_SKILL/REQUIRES/TEACHES/PREREQUISITE
2. 从 data/processed/ 导入的构建脚本
3. 查询接口:岗位技能要求、课程覆盖技能、前置链路

验收:导入后能查询"AI Engineer 需要什么技能"及"Develop AI Agents 的前置课程"。
```

## 阶段 2B:画像与 Skill Gap(依赖阶段 0/1,可与 2A 并行)

```
阅读 prompts/大纲.md 第五、六节。

实现 profile/:
1. 员工画像:技能等级 + Evidence(考试/项目/自评/培训记录)
2. Skill Gap 计算(纯算法,不用 LLM):目标岗位要求 vs 当前等级
3. 输出结构化差距报告(缺失技能 + 差距值)

验收:给定示例员工与 AI Engineer 岗位,输出正确 Gap 列表;pytest 覆盖。
```

## 阶段 3A:课程推荐(依赖 2A/2B)

```
阅读 prompts/大纲.md 第七节。

实现 recommendation/:
1. Candidate Generation:按 Skill Gap 从图谱找 TEACHES 关系课程
2. Course Ranking:Gap 覆盖度/技能重要性/难度匹配/前置满足/时间成本加权打分
3. 输出 Top-K 及推荐理由数据(供 LLM 解释用)

验收:示例员工输入输出合理 Top-5;排序可单测。
```

## 阶段 3B:学习路径(依赖 2A/3A)

```
阅读 prompts/大纲.md 第八节。

实现 learning_path/:
1. 课程 DAG(前置关系),剪枝已掌握课程
2. 拓扑排序 + 每周可学时间约束 → 周计划输出
3. 8 周计划示例可复现

验收:给定 Gap 与时间约束输出合法拓扑序周计划。
```

## 阶段 4:RAG + Agent(依赖阶段 0-3)

```
阅读 prompts/大纲.md 第九、十节。

实现 rag/ 与 agent/:
1. RAG:文档解析→标题级分块→Embedding→pgvector→检索→重排
2. LangGraph HR Training Agent,工具:员工画像/岗位查询/Skill Gap/
   课程搜索/推荐/学习路径/RAG 问答
3. CLI 交互入口

验收:示例问题"为什么推荐我学 AI Agent?"能引用检索内容作答。
```

## 阶段 5:反馈闭环(依赖全部)

```
阅读 prompts/大纲.md 第十一节。

实现 feedback/:
1. 培训记录与考试写入(training_record/assessment)
2. Skill Evidence 更新 → 画像刷新 → Gap 重算 → 推荐与路径动态调整
3. 集成测试:完成课程后路径缩短的端到端用例
```
